FB AUTOPOST · BROWSER EDITION 1.2

บัญชี Facebookล็อกอินบน Facebook โดยตรง ไม่ต้องวางโทเคน

กำลังเชื่อมต่อ…

1 · บัญชี Facebook

วิธีล็อกอิน

กดล็อกอิน → Chrome เปิด facebook.com → เข้าสู่ระบบและยืนยันตัวตนเอง → กลับมากดตรวจล็อกอิน เซสชันถูกเก็บในโปรไฟล์แยกบัญชีบนคอมเครื่องนี้ โปรแกรมไม่รับรหัสผ่าน ไม่ต้องใช้ Meta App

2 · เตรียมโพสต์

เตรียมร่าง: ตรวจและกดโพสต์เองใน Chrome · เริ่มรอบ: ส่งตามลิงก์ที่กำหนดหนึ่งรอบ ไม่วนซ้ำ

Log การทำงาน

สิ่งที่รองรับและข้อจำกัด

หลายบัญชี โปรไฟล์แยก เปิดล็อกอิน ตรวจเซสชัน โหลดลิงก์กลุ่มที่เห็นบนหน้าจอ เตรียมร่าง และส่งข้อความลงกลุ่มหนึ่งรอบ Facebook อาจเปลี่ยนหน้าจอ ขอ CAPTCHA หรือ 2FA ซึ่งคุณต้องดำเนินการเอง หากไม่ยืนยันผล โปรแกรมหยุดรอบเพื่อไม่ส่งซ้ำ

ยังไม่มีรูปแนบ ดันคอมเมนต์ กดไลค์ แชร์ หรือ Discord user-token ต้องติดตั้ง Google Chrome ก่อน เปิดโปรแกรมและคอมค้างไว้ขณะทำงาน ปุ่มหยุดจะหยุดงานถัดไป ไม่ย้อนกลับโพสต์ที่ส่งแล้ว

รุ่นแก้ไขต่อจากซอร์ส v0.6.10 โดยรักษา app ID และโฟลเดอร์ข้อมูลเดิม

- แก้การเริ่ม/หยุดคิวซ้อน และรอคิวระหว่างปิดโปรแกรม
- แก้ Windows quit ค้างจากการเรียก quit ซ้ำใน native event เดิม
- แยกผลส่ง Discord ที่ไม่แน่นอน ป้องกันการลองใหม่ที่อาจส่งซ้ำ พร้อม timeout และตรวจ message ID
- แก้ cooldown หลัง HTTP 429 และไม่ทำให้บัญชีติดสถานะจำกัดอัตราถาวร
- หยุดตารางแล้วยกเลิกงานรอ/งานรอตรวจรวมขั้นตอนลูก
- กันลบบัญชีหรือปลายทางขณะงานกำลังทำ และไม่ถือว่าเปิด Chrome = ล็อกอินสำเร็จ
- สำรอง SQLite ก่อน migration 9 และทดสอบการเปิดฐานข้อมูลซ้ำ
- แก้การรอช่องความคิดเห็นและขนาดหน้าต่างบนจอเล็ก/Windows scaling
- Notification/renderer observer ที่เสียไม่เปลี่ยนโพสต์สำเร็จเป็นล้มเหลว

ตรวจ TypeScript, build และ 112 tests ผ่าน รวม Windows CI ที่สร้าง installer และเปิด/ปิด packaged app ในโหมดปิดคิวด้วยข้อมูลชั่วคราว โดยไม่ส่งโพสต์จริง
Desktop Python เดิมยังอยู่ และชุดตรวจเดิมผ่าน 19 tests พร้อม Windows desktop verification

Comment/Share/Like/Follow-up, pending approval detector และ group permission checks ยังคงปิดตาม feature flags ของ v0.6.10 ไม่ได้อ้างว่าผ่าน Facebook live E2E
การทดสอบ packaged app ไม่ใช่การรันขั้นตอนติดตั้ง/ถอนติดตั้งครบทุกเครื่อง

ก่อนอัปเดต หยุดคิว รอให้งานจบ และเลือกออกจาก System Tray จากนั้นติดตั้งรุ่นใหม่ในตำแหน่งเดิม ข้อมูลบัญชีไม่ได้รวมอยู่ในไฟล์ดาวน์โหลด

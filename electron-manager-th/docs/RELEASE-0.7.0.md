# AutoPost Manager TH 0.7.0

ปรับหน้าจอแบบ macOS โทนสว่าง กระจกด้าน เมนูแยกตามงาน รองรับหน้าต่างตั้งแต่ 800px และการลดแอนิเมชันของระบบ

## เริ่มใช้งาน
1. หยุดคิว รอให้งานที่กำลังส่งจบ แล้วออกจากรุ่นเดิมผ่าน System Tray ก่อนติดตั้ง ใช้ App ID และพื้นที่ข้อมูลเดิม ไม่ลบประวัติเก่า
2. เมนู **บัญชีและปลายทาง** → ล็อกอิน Chrome หรือนำเข้า Cookie ของบัญชีคุณ → ตรวจ Session → ดึงกลุ่ม เลือกกลุ่มที่ต้องการบันทึกเป็นปลายทาง
3. เมนู **โปรไฟล์ข้อความ** → โพสต์ หรือ ดันความคิดเห็น → โปรไฟล์ใหม่ → กรอกชุด A/B (ลบชุดว่างได้) → บันทึก หรือ Ctrl+S / Cmd+S
4. แต่ละชุดใส่ลิงก์บรรทัดละหนึ่งรายการ ข้อความ และรูป โพสต์เลือกโฟลเดอร์และแนบทุกรูปในโฟลเดอร์ (สูงสุด 10 รูป ไม่รวมโฟลเดอร์ย่อย อ่านรายการรูปใหม่ทุกรอบ) ความคิดเห็นแนบได้หนึ่งรูป
5. ตั้งตารางโปรไฟล์ เลือกบัญชี/โปรไฟล์ เวลาไทย จำนวนรอบ (0 = วนต่อเนื่อง) ระยะห่างรอบ และเวลาพักระหว่างเป้าหมาย เลือกได้จากหน้าบัญชีเช่นกัน
6. เปิดระบบคิว เครื่องต้องเปิด ไม่หลับ และเชื่อมต่ออินเทอร์เน็ต ปิดหน้าต่างจะซ่อนไว้ใน Tray การออกจาก Tray หยุดโปรแกรม
7. ตรวจผลที่ **คิวและประวัติ** กับ **Log** หยุดตารางโปรไฟล์ได้จากรายการตารางในหน้าบัญชีหรือโปรไฟล์

## เนื้อหาและตาราง
- หนึ่งโปรไฟล์มีหลายชุด ทุกลิงก์ใช้ข้อความและรูปของชุดนั้นเสมอ ลิงก์ไม่ซ้ำข้ามชุด สุ่มลำดับใหม่ทุกรอบ
- หลายบัญชีใช้โปรไฟล์เดียวกันได้ การแก้แล้วบันทึกมีผลในรอบถัดไป คิวที่สร้างแล้วเก็บเนื้อหาเดิมให้ตรวจสอบย้อนหลังได้
- ตั้งเวลาต่อบัญชี แยกโพสต์กับความคิดเห็น ห้ามเปิดโปรไฟล์ชนิดเดียวกันซ้อนในบัญชีเดียว
- รอบใหม่รอคิวรอบเดิมจบ ถ้าเลยเวลาเกิน 5 นาทีจะพักตารางให้ผู้ใช้ตรวจและตั้งใหม่ ไม่ไล่ส่งรอบที่พลาดติดกัน
- งานรออนุมัติกลุ่มบันทึกเป็น **รออนุมัติ** ไม่ใช่เผยแพร่สำเร็จ แล้วไปเป้าหมายถัดไป ข้ามเป้าหมายที่ยังมีสถานะรออนุมัติในรอบใหม่ ไม่สะสมโพสต์รอซ้ำ
- ยังไม่ติดตามการอนุมัติย้อนหลังอัตโนมัติ ให้ตรวจบน Facebook เอง สถานะที่ไม่แน่ชัดจะไม่ส่งซ้ำ
- หยุดตารางจะยกเลิกคิวที่ยังไม่ส่ง รวมงานแชร์ซ้ำของตาราง งานที่กำลังส่งจะรอให้จบ เก็บประวัติส่งแล้ว

## แชร์ / ดันความคิดเห็น / ถูกใจ
- เปิดใช้งานโค้ดทั้งสามแบบ พร้อมหน้าจอเลือกขั้นตอนและตั้งเวลาชัดเจน
- แชร์โพสต์ที่มีอยู่: เมนู **แชร์ / คอมเมนต์ / ถูกใจ** → ใส่ลิงก์ถาวรต้นฉบับ → เลือกกลุ่ม → เวลา → เพิ่มคิว แชร์ซ้ำได้ตามนาที
- แชร์คู่กับโพสต์: ตั้งตารางโปรไฟล์ในหน้าบัญชี → เลือกโปรไฟล์โพสต์ → ติ๊กแชร์ → เลือกกลุ่ม ระบบแชร์เมื่อยืนยันโพสต์ต้นฉบับพร้อมลิงก์ถาวรแล้วเท่านั้น
- แชร์ซ้ำคู่กับโปรไฟล์ใช้ได้เมื่อโปรไฟล์ตั้ง 1 รอบ เพื่อไม่สร้างตารางวนซ้อน เลือกวนโปรไฟล์หลายรอบได้โดยปิดแชร์ซ้ำ
- แชร์แบบ Facebook ใช้รูปต้นฉบับ เปลี่ยนรูปให้ใช้สร้างโพสต์ใหม่พร้อมลิงก์ต้นฉบับ
- กลุ่มแชร์แต่ละกลุ่มเป็นงานอิสระ กลุ่มหนึ่งรออนุมัติไม่ยกเลิกกลุ่มอื่น
- ตรวจรหัสกลุ่มก่อนแชร์ หาก Facebook ไม่แสดงหลักฐานรหัสกลุ่มที่เลือกจะหยุดก่อนส่ง ไม่เลือกจากชื่อโดยเดา
- สำเร็จต้องพบหลักฐานใหม่ตรงกลุ่ม บัญชี และลิงก์ต้นฉบับ หน้าต่างแชร์ปิดอย่างเดียวไม่ถือว่าสำเร็จ
- CAPTCHA, checkpoint หรือข้อจำกัดบัญชีต้องจัดการด้วยตนเอง ไม่มีการข้ามการยืนยันของ Facebook

## บัญชีและกลุ่ม
- ใช้ระบบ Cookie เดิม: Cookie-Editor JSON หรือ c_user=…; xs=… รองรับหลายบัญชี ตรวจ Session ก่อนทำงาน และคัดลอก Cookie จากหน้าบัญชีได้
- ตรวจ c_user ให้ตรงกับบัญชีก่อนทุก action ป้องกันทำงานผิดบัญชี
- เพิ่มการไล่โหลดกลุ่มถึง 100 รอบ พร้อมเลื่อนแผงที่เลื่อนได้ เก็บชื่อและรูปที่ Facebook ส่งมา ไม่ลบกลุ่มเก่าเมื่อการโหลดครั้งใหม่ได้ไม่ครบ
- จำนวนกลุ่มขึ้นกับสิทธิ์และหน้า Facebook ไม่รับประกันว่าทุกกลุ่มจะถูกแสดง

## ขอบเขตการทดสอบ
ตรวจ TypeScript, build, ชุดทดสอบฐานข้อมูล/คิว/โปรไฟล์ และเบราว์เซอร์จำลองการแชร์ รออนุมัติ สลับบัญชี และกรณีไม่พบหลักฐานเผยแพร่ รวมการจัดหน้าจอ 8 เมนูที่ 800/1024/1440px

ไม่มีการส่งโพสต์ แชร์ ความคิดเห็น หรือไลก์จริงจากบัญชีผู้ใช้ในการตรวจครั้งนี้ โครงสร้างหน้า Facebook และสิทธิ์บัญชีแต่ละบัญชีอาจต่างจากหน้าจำลอง

## ชุดพัฒนา: เมนูเพจและโปรไฟล์ข้อความ
ส่วนนี้เพิ่มในซอร์สเท่านั้น EXE ใน downloads ยังเป็น 1.3.1 เดิม
- เมนูโพสต์แบบเพจ: Page ID + Page Access Token, ข้อความ/ลิงก์, ส่งทันทีหรือตั้งเวลาตามเครื่อง, ดูสถานะและยกเลิกงานที่รอ
- โปรไฟล์ข้อความแยกบัญชี: สร้างข้อความหลายบรรทัด เลือกกลุ่มแล้วผูกโปรไฟล์ ใช้กับร่างและรอบโพสต์ บันทึกแบบ atomic
- ดึงกลุ่มสูงสุด 80 รอบเลื่อน / 500 กลุ่ม หรือหยุดเมื่อจำนวนไม่เพิ่ม 5 รอบ ยังไม่รับประกันครบ
- ข้อผิดพลาดการโพสต์แสดงชนิด error เพื่อช่วยวินิจฉัย โดยไม่เผยข้อมูลบัญชี
- รูปแนบ, native share/แชร์ซ้ำ, ดันเมนต์, cookie import/export, Discord และการทำงานขนานยังไม่เพิ่มในชุดนี้
- ไม่เพิ่มระบบหลายบัญชีกดไลก์เพื่อปั่นยอด
- ต้องเปิดโปรแกรมค้างไว้ งานเพจยังต้องเชื่อมโทเคนใหม่หลังปิดโปรแกรม
ตรวจ unit tests 22 รายการและ JavaScript syntax ผ่าน ยังไม่ทดสอบ Facebook จริงหรือ UI ใหม่ใน Windows

# FB AutoPost 1.3.1 — Desktop

[ดาวน์โหลด FB-AutoPost-Setup.exe](https://github.com/bouricx/fb-autopost/raw/refs/heads/main/downloads/FB-AutoPost-Setup.exe)

## ใหม่ในรุ่น 1.3.1
เปิดเป็นหน้าต่าง Desktop ด้วย WebView2 ไม่มีแท็บหน้าจัดการใน Chrome
แก้พอร์ต 8765 ชน: จองพอร์ตว่างและรอ server พร้อมก่อนเปิดหน้าต่าง
เปิดซ้ำรุ่นเดียวกันจะกลับไปหน้าต่างเดิม ไม่เปิด server ซ้อน
ปิดหน้าต่างแล้วระบบสั่งหยุดงาน พอร์ตภายในไม่ต้องกรอกเอง
หากเครื่องไม่มี Microsoft Edge WebView2 Runtime ให้ติดตั้งจาก Microsoft ก่อน
(https://developer.microsoft.com/microsoft-edge/webview2/)
ล็อกอินและโพสต์ Facebook ยังเปิด Chrome แยกตามบัญชีตามเดิม

## ใหม่ในรุ่น 1.3
หน้าจอ Liquid Glass แยกบัญชี / กลุ่ม / เขียนโพสต์ / ประวัติ พร้อมโหมดสว่างและมืด
ดึงชื่อและรูปกลุ่มจากหน้าที่บัญชีล็อกอินมองเห็น เก็บแยกแต่ละบัญชี
ค้นหา เลือกกลุ่ม และนำรายการที่เลือกไปยังหน้าเขียนโพสต์ได้
รูปดึงจาก Facebook CDN; ถ้าไม่มีรูปหรือ URL หมดอายุแสดงอักษรย่อของชื่อกลุ่ม
กดดึงข้อมูลอีกครั้งเพื่ออัปเดต ชื่อและรูปไม่ได้ดึงมาจาก Meta API หรือข้อมูลสาธิต

## ใช้บน Windows 10/11 x64
1. ติดตั้ง Google Chrome ให้เรียบร้อย (https://www.google.com/chrome/)
2. ดาวน์โหลด EXE แล้วดับเบิลคลิก รอแตกไฟล์ครั้งแรกแล้วเปิดหน้าต่างโปรแกรม FB AutoPost โดยตรง
3. พิมพ์ชื่อบัญชี เช่น Veltshop แล้วกด เพิ่มบัญชี → ล็อกอิน
4. Chrome หน้าต่างแยกเปิด facebook.com ให้เข้าสู่ระบบบน Facebook เอง รวมถึง 2FA
5. กลับโปรแกรมแล้วกด ตรวจล็อกอิน สถานะ “พบเซสชันล็อกอิน” เป็นการตรวจ cookie
   บ่งชี้เซสชัน ไม่รับประกันว่า Facebook จะไม่ขอยืนยันตัวตนอีก
6. เลือกบัญชี กด โหลดกลุ่มที่ฉันเข้าร่วม หรือวางลิงก์กลุ่มเอง
7. พิมพ์ข้อความ แล้วกด เปิดและเตรียมร่าง เพื่อตรวจและกดโพสต์เองใน Facebook
8. หากต้องการส่งหนึ่งรอบ กด เริ่มรอบโพสต์ แล้วยืนยันกลุ่มและข้อความ
   แต่ละรอบจำกัด 20 กลุ่ม พักตามเวลาที่ตั้ง ปุ่มหยุดกันการส่งงานถัดไป

ไม่ต้องวาง User Access Token ไม่ต้องมี Meta App ไม่กรอกรหัสผ่านในโปรแกรม
เซสชันเก็บในโปรไฟล์ Chrome แยกต่อบัญชี ใช้บัญชีที่มีสิทธิ์โพสต์ในกลุ่มนั้น
กรณี CAPTCHA/2FA ต้องดำเนินการบน Facebook เอง ไม่มีระบบข้ามการตรวจสอบ
Chrome ที่ใช้เป็นโปรไฟล์ของแอป ไม่อ่านหรือคัดลอกโปรไฟล์ Chrome ส่วนตัว

## งานที่รองรับจริง
หลายบัญชี, เปิดล็อกอิน, ตรวจเซสชัน, โปรไฟล์แยก, โหลดลิงก์กลุ่มที่เห็นในหน้า,
เตรียมข้อความ, ส่งข้อความลงกลุ่มหนึ่งรอบ, หยุดงาน, ปิดเบราว์เซอร์, Log
หากโพสต์กลุ่มต้องรออนุมัติ ผลใน Log ไม่ได้หมายความว่าผู้ดูแลอนุมัติแล้ว
หากปุ่ม/หน้า Facebook เปลี่ยนหรือไม่ยืนยันผล โปรแกรมหยุดรอบและไม่ลองส่งซ้ำเอง
โหลดกลุ่มได้เฉพาะที่หน้าจอแสดงในช่วงเลื่อน 8 ครั้ง อาจไม่ครบทุกกลุ่ม
ยังไม่มีรูปแนบ, ดันคอมเมนต์, กดไลค์, แชร์, วนรอบ, ตั้งเวลาแบบ browser หรือ
Discord user-token แบบโปรแกรมในคลิป ระบบ Page API เดิมยังอยู่ในซอร์สแต่ไม่อยู่
ในหน้าจอหลักของ Browser Edition เว็บ API โหมดเดิมยังต้องใช้โทเคน

## ที่เก็บข้อมูล
EXE แตกไฟล์ใน %LOCALAPPDATA%\FB-AutoPost\v1.3.1\FB-AutoPost
บัญชีและโปรไฟล์ใหม่เก็บที่ %LOCALAPPDATA%\FB-AutoPost\user-data
หากพบข้อมูลรุ่น 1.2 อยู่ก่อน โปรแกรมจะใช้โฟลเดอร์ app ของรุ่น 1.2 ต่อ
เพื่อรักษาบัญชีและเซสชันเดิม กรุณาอย่าลบโฟลเดอร์เดิมนี้
ห้ามส่งโปรไฟล์/cookies/config ที่มีความลับขึ้น GitHub สำรองข้อมูลก่อนอัปเกรด
ตัวโปรแกรมรุ่น 1.3 แยกโฟลเดอร์ติดตั้งจากรุ่นก่อน
หยุดโปรแกรม = หยุดงาน ไม่ใช่ Windows service ไม่มีอัปเดตอัตโนมัติ
